## C题：双重循环扫描所有情况太笨重了

尽管思路是正确的，但是时间复杂度是O(n^2)，使用dp，从左到右扫一遍，再从右到左扫一遍即可，时间复杂度为O(n)。

从左往右扫，观察当前元素与前一元素的关系。在未扫到任何不同元素之前，记录都为INF，若不等则为1，更新答案进入下一元素。若后一元素与当前元素相等，则将dist+1记录进去。
再从右往左扫，此时把先前的ans和当前的dist作比较，保留最小值。

核心代码：
```cpp
int dist=INF;//int INF=1e9
for(int i=1;i<n;i++)
{
	if(a[i]!=a[i-1])
		dist=1;
	else if(dist!=INF)
		dist++;
	ans[i]=dist;
}
dist=INF;//重置dist
for(int i=n-2;i>=0;i--)
{
	if(a[i]!=a[i+1])
		dist=1;
	else if(dist!=INF)
		dist++;
	ans[i]=min(ans[i],dist);
}
```
