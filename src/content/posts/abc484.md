## C 题：两个方向都要尝试

C题有三种情况可以输出`"Yes"`，`A` 数组等于`B`数组，不同区间中`A`把区间起点的元素移动到了最后面得到`B`，不同区间中`A`把区间终点的元素移动到了最前面得到`B`。（先从0向n遍历直到寻找到两数组元素不同时，记录当前位置为`posl`，再从n-1向posl遍历，记录右侧不同位置为`posr`，`[posl,posr]`则为不同区间）

在寻找posl时，就可以判断第一种情况是否成立，当`posl==n-1`A数组等于B数组直接输出`"Yes"`；

若不同区间存在，我们用两个bool变量初判断是那种类型的移动，c1代表A是否把区间起点的元素移动到了最后面得到B，c2则代表A把区间终点的元素移动到了最前面得到B；

进行了初次判断后，我们再对不同区间内的元素进行判断。由于只进行了一次移动，我们只需要根据移动类型判断是否满足对应的变换，若不满足则相对应的bool变量变为false

核心代码：
```cpp

bool c1=(a[posl]==b[posr]);
for(int i=posl+1;i<=posr;i++)
{
	if(a[i]!=b[i-1])
	    c1=false;
}
for(int i=posl;i<posr;i++)
{
    if(a[i]!=b[i+1])
        c2=false;
}	
cout<<("Yes":"No"?(c1||c2))<<'\n';
```
卡点分析：最初我只是使用if . . . else if根据是否满足c1再对不同区间里的进行c1对应的判断，因此忽略了对c2条件的判断，这是一种非此即彼的误判 。

学长提供的思路：对两数组从左向右读取，遇到不同后进行操作
```cpp
int l=-1;
bool ans=true;
bool shiftleft=true,shiftright=true;
for(int i=0;i<n;i++)
{
	if(l==-1)//还未记录时
	{
		if(a[i]==b[i])continue;
		l=i;
	}
	if(i>l)
	{
		if (a[i]!= b[i-1])shiftLeft=false;
        if (a[i-1]!=b[i])shiftRight=false;
	}
	if(a[i]!=b[i])
	{
		ans=((shiftleft&&a[l]==b[i])||(shiftright&&a[i]==b[l]));//最终记录的答案等价于(shiftleft&&a[posl]==b[posr])||(shiftright&&a[posr]==b[posl])
	}
}

cout<<(ans?"Yes\n":"No\n");
```

## D题：把相邻相同元素的重复计算弄清楚

补D题时，我在草稿纸上大致的找了一下规律。对于第i个元素，有i个空位供他插入，若他前面相邻元素与他相等，则跳过他，寻找第i-1个元素可插入的位置（因为可插入的点相同）。确定下了i，若前面有j个相同元素，则有i-j种情况。

核心代码：
```cpp
int n;
  cin>>n;
  vector<int> a(n);
  unordered_map<int,int> cnt;
  for(int i=0;i<n;i++)
  {
    cin>>a[i];
    cnt[a[i]]++;
  }
  long long ans=1;
  for(int i=n-1;i>0;i--)
  {
    long long sum=i;
    cnt[a[i]]--;
    if(a[i]==a[i-1])continue;
    sum-=cnt[a[i]];
    ans+=sum;
  }
  cout<<ans<<'\n';
```
## E题：使用树状数组+二分查找找出所有符合的区间并求和其数量

初见这一题时，我先是想到用双层循环暴力模拟，但是觉得不现实，于是就借鉴学习了一下。

先引入树状数组：
```cpp
int lowbit(int i){return i&(-i);}
void add(int i,long long x)
{
	while(i<(int)tree.size())
	{
		tree[i]+=x;
        i+=lowbit(i);
    }
}
long long query(int i)
{
    long long ans=0;
    while(i>0)
    {
        ans+=tree[i];
        i-=lowbit(i);
    }
    return ans;
}
```
注意这里add中i的范围直接与tree的大小相关。

我们先用s[]记录前缀和，再用`v`处理`s`中的元素，复制排序再去重。tree[]则的对应v[]中元素的数量。在处理s[i]之前，先给tree[]内对应s[0]的元素add(1)。对于每个s[i]，为满足题意使得每个区间在[L,R]内，我们要让`ans`加上所有和为[s[i]-R,s[i]-L](L<=s[i]-x<=R)的旧前缀和，而旧前缀和出现次数存在tree内，用树状数组查出现次数，累加到ans。最后执行add(rank(s[i]),1)供下一轮查找。

核心代码：
```cpp
vector<long long> v=s;
sort(v.begin(),v.end());
v.erase(unique(v.begin(),v.end()),v.end());
tree.resize((v.size()+1),0);
int pos=lower_bound(v.begin(),v.end(),s[0])-v.begin()+1;
add(pos,1);
for(int i=1;i<=n;i++)
{
	long long LB=s[i]-R;
	long long RB=s[i]-L;
	int below=lower_bound(v.begin(),v.end(),LB)-v.begin();
	int through=upper_bound(v.begin(),v.end(),RB)-v.begin();
	ans+=query(through)-query(below);
	int pos=lower_bound(v.begin(),v.end(),s[i])-v.begin()+1;
	add(pos,1);
}
```
