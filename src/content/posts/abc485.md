## C题：双重循环扫描所有情况太笨重了

尽管思路是正确的，但是时间复杂度是O(n^2)，使用dp，从左到右扫一遍，再从右到左扫一遍即可，时间复杂度为O(n)。

从左往右扫，观察当前元素与前一元素的关系。在未扫到任何不同元素之前，记录都为INF，若不等则为1，更新答案进入下一元素。若后一元素与当前元素相等，则将dist+1记录进去。
再从右往左扫，此时把先前的ans和当前的dist作比较，保留最小值。

核心代码：
```cpp
int dist=INF;//int INF=1e9
for(int i=1;i<n;i++)
{
	if(a[i]!=a[i-1])
		dist=1;
	else if(dist!=INF)
		dist++;
	ans[i]=dist;
}
dist=INF;//重置dist
for(int i=n-2;i>=0;i--)
{
	if(a[i]!=a[i+1])
		dist=1;
	else if(dist!=INF)
		dist++;
	ans[i]=min(ans[i],dist);
}
```
## D题：固定一个端点去记录另一个端点||滑动窗口

### 两种写法：
(1)固定端点记录另一个端点

我们对第二刀从最开始向右进行移动，每次向右移动一次减去第三段对应的字符，直到第三段的一种字符为0，此时为第二刀的右边界。记录第一个ABC最靠左的位置，其中最靠左的为earliest。当ABC都出现时，earliest都不为0，记录位置为firstCut,此处为第一刀最左边的位置。固定每个第二刀位置，同时记录ABC中最靠左的位置，第一刀可出现的情况即为（earliest-firstCut）。把所有情况加起来就是ans。
```cpp
int remain[3]={};
for(char c:s)
	remain[c-'A']++;
int last[3]={};
int firstCut=0;
long long ans=0;
for(int j=1;j<n;j++)
{
	int c=s[j-1]-'A';
	last[c]=j;
	remain[c]--;
	
	if(remain[c]==0)break;
	int earliest=min({last[0],last[1],last[2]});
	if(earliest==0)continue;
	if(firstCut==0)firstCut=j;
	ans+=max(0,earliest-firstCut);
}
cout<<ans<<'\n';
```
(2)滑动窗口

最先做一件事情:给第一段第二段留足字符，即为寻找L和R，方法与前一种方法一致。

寻找L，R部分：
```cpp
int L=0;R=n-1;
for(char c:string("ABC"))
{
	auto first=s.find(c);
	if(first==string::npos)
	{
		cout<<0<<'\n';
		return 0;
	}
	int last=(int)s.rfind(c);
	L=max(L,(int)first+1);
	R=min(R,last-1);
}
```

找到区间了，开始滑动窗口：
从L开始移动r到R：
（1）如果窗口内未凑齐"ABC"，则r向右移动。
（2）如果已经凑齐，就看最左边的字符，只要他在cnt至少为2，就可以移动l。
（3）l不发生改变时，就是最靠右的合法起点。

滑动窗口部分：
```cpp
long long ans=0;
int cnt[3]={};
int l=L;
for(int r=L;r<=R;r++)
{
	cnt[s[r]-'A']++;
	if(cnt[0]==0||cnt[1]==0||cnt[2]==0)continue;
	while(cnt[s[l]-'A'>1)
	{
		cnt[s[l]-'A']--;
		l++
	}
	ans+=l-L+1;
}
```
最重要在于当cnt[i]都不为0，ans就要加1，如若左端点可移动，加上l－L；
